# 🛒 쇼핑 리스트

간단한 쇼핑 리스트 웹 앱입니다. 별도 설치나 서버 없이 브라우저에서 `shopping-list.html` 파일만 열면 바로 사용할 수 있습니다.

## 주요 기능

- 아이템 추가 / 삭제
- 체크박스로 완료 표시 (완료 시 취소선 표시)
- 완료된 항목 일괄 삭제
- 전체 항목 수 및 완료 개수 표시
- `localStorage`를 이용한 데이터 자동 저장 (브라우저를 새로고침하거나 닫았다 열어도 목록 유지)

## 사용법

1. `shopping-list.html` 파일을 더블 클릭하거나 브라우저의 파일 열기(Ctrl+O)로 실행합니다.
2. 상단 입력창에 항목을 입력하고 `추가` 버튼을 누르거나 `Enter` 키를 눌러 아이템을 추가합니다.
3. 목록에서 항목을 클릭하거나 왼쪽 원형 체크박스를 클릭하면 완료 여부가 토글됩니다.
4. 항목 오른쪽의 `✕` 버튼으로 개별 삭제가 가능합니다.
5. 상단 통계 영역의 `완료 항목 삭제` 버튼으로 완료된 항목을 한 번에 정리할 수 있습니다.

## 기술 스택

- HTML / CSS / Vanilla JavaScript (프레임워크 없음)
- 브라우저 `localStorage`를 이용한 클라이언트 사이드 데이터 저장
